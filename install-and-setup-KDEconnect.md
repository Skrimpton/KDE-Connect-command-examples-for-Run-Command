# Get KDEconnect - *use [GSConnect](https://extensions.gnome.org/extension/1319/gsconnect) on Gnome*

### Get : PHONE
- [Google play](https://play.google.com/store/apps/details?id=org.kde.kdeconnect_tp)
- [Fdroid](https://f-droid.org/packages/org.kde.kdeconnect_tp/) 

### Get : Linux PC (if not pre-installed)

| **Distribution** | **Package Manager** | **Installation Command** |
|---|---|---|
| **Debian** | apt | `sudo apt-get install kdeconnect` |
| **Ubuntu** | apt | `sudo apt install kdeconnect` |
| **Arch/Manjaro** | pacman | `sudo pacman -S kdeconnect` |
| **openSUSE** | zypper | `sudo zypper install kdeconnect` |
| **Red Hat/Fedora** | dnf | `sudo dnf install kde-connect` |
| **Distribution neutral** | Flatpak | `flatpak install flathub org.kde.kdeconnect` |
